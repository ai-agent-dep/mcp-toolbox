# 现有 Toolbox 配置管理

管理现有部署前先读 `README.md` 与 `CONFIGURATION.md`。当前是远程服务器的
systemd 服务，不是本地 Docker。以服务器实时配置为准，先读取并保留无关对象，
不要用仓库空模板覆盖已有数据库。运行版本以远程 `--version` 为准。

使用 `check-config.py` 和当前版本原生格式，先校验候选再应用；应用后检查健康、
MCP 初始化、完整工具列表及受影响组，失败则恢复本次备份并验证。环境变量修改
需要重启。不要把连接密码、展开后的配置、原生日志中的敏感信息输出到聊天或 Git。

不凭空新增数据库；默认只提供固定、参数绑定的查询。实际数据库连接、权限和
MCP 访问认证必须在接入时核实。组是路由范围，不是授权边界。记录无法实测的项目。
